LIVE TSDB • 1s/30s Stream (3,600 pts)
CORE INSIGHT 왜 기존 30초 소켓 상태 보고만으로는 AGV 무선 끊김을 사전 감지하거나 원인을 밝힐 수 없는가?

이동 중인 AGV의 로밍 지연·전파 음영·소켓 버퍼 적체는 3~15초 이내에 급격히 진행되어 30초 보고 주기 사이에 예고 없이 연결이 끊어집니다. 본 시스템은 Stage 1(AGV 로컬 1초 링버퍼) + Stage 2(30초 통계 피기백) + Stage 3(단절 18초 전 조기 경보 & 사후 블랙박스 덤프)를 내장형 시계열 DB(TSDB)로 실시간 시연합니다.

AGV/ACS 소켓 블로킹 (Hang)

무선(RSSI/RTT)은 완벽히 정상이나 AGV SLAM CPU(96%) 폭주 및 Recv-Q 적체로 30초 보고 타임아웃

[SCN-01] AP 로밍 실패 — 30초 주기 보고 사각지대 vs 1초 하이브리드 사전 감지 타임라인 비교

❌ 기존 30초 주기 소켓 보고 관점 (Legacy 30s Socket Polling) 사전 감지 불가 / 원인 불명

T-30초 시점 보고에서는 정상 수준으로 보고되었으나, 이후 30초 사이에 발생한 급격한 지표 악화를 전혀 인지하지 못하고 T=0초에 갑작스러운 Socket Timeout(단절)을 맞이하므로 원인을 알 수 없습니다.

✅ 제안 하이브리드 1초 수집 + 사전 감지 관점 (Hybrid 1s + Piggyback) 단절 18초 전 조기 경보 발령!

AGV 로컬 1초 링버퍼가 지표 기울기와 재전송 급증을 실시간 추적하여 30초 소켓이 끊어지기 18초 전(T-18s)에 EWMA 위험도 70점을 돌파, ACS로 즉시 조기 경보를 푸시하고 재연결 후 120초 블랙박스 덤프로 원인을 100% 규명합니다.

기존 30초 소켓 보고의 구조적 한계와 3단계 하이브리드 수집 아키텍처 (Hybrid Telemetry Pipeline)

네트워크 부하 < 45 bps/AGV • CPU 부하 < 0.2%

AGV 전체 플릿이 매 1초마다 모든 무선/소켓 지표를 ACS로 실시간 전송하면 무선 채널 경쟁(Contention)과 ACS 소켓 처리 부하가 증가합니다. 반면 기존처럼 30초 주기로만 보고하면 29.9초의 사각지대(Blind Spot)가 발생합니다. 이를 완벽히 해결하는 3단계 하이브리드 수집 모델입니다.

STAGE 1 • 1s Local Ring Buffer 무선 트래픽 0 Byte

AGV 온보드 1초 고주파 링버퍼 수집

AGV 내부 데몬이 Linux 커널 인터페이스(/proc/net/wireless, nl80211, NETLINK_INET_DIAG tcp_info)에서 1초마다 18개 지표를 메모리 링버퍼(최근 5분, 144KB)에 기록합니다.

• 수집 주기: 1.0초 (고해상도)
• AGV CPU 부하: 0.14% 미만 (커널 구조체 직접 읽기)
• 평시 무선 전송: 없음 (로컬 메모리 순환 보관)
STAGE 2 • 30s Statistical Piggyback +96 Bytes / 30s

평시 30초 ACS 상태 보고에 통계 요약 피기백

별도의 모니터링 소켓을 열지 않고, 기존 30초 주기 ACS 상태 보고 TCP 패킷 끝에 지난 30초간의 핵심 통계 요약(`min/avg/max/delta`) 블록만 피기백(첨부)하여 전송합니다.

• 포함 지표: rssi_min/avg, snr_min, l2_retry_max, tcp_retrans_sum, gw_rtt_max, risk_max
• 대역폭 오버헤드: 약 25.6 bps/AGV (무시 가능 수준)
• 활용: 공장 전역 음영 히트맵 및 장기 추세 분석
STAGE 3 • Early Warning & Blackbox Dump 이벤트 트리거

조기 경보 푸시(T-18s) & 재연결 블랙박스 덤프

1초 로컬 감시 중 EWMA 위험도 ≥ 70점 도달 시 30초 주기를 기다리지 않고 즉시 경량 조기 경보 패킷을 푸시합니다. 만약 단절 후 재연결되면 단절 전후 ±60초(120초) 1초 파형 덤프를 전송합니다.

• 사전 감지 선행 시간: 단절 평균 14~18초 전 경보
• 제어 연동: AGV 감속 / 대기 / 802.11v 선제 로밍 명령
• 사후 분석: 4대 장애 시나리오 100% 자동 판별

실제 프로토콜 패킷 규격 인스펙터 (JSON Schema)

기존 30초 ACS 상태 보고 JSON 페이로드에 `net_telemetry_30s` 요약 객체(약 96~128 Bytes)를 피기백한 실제 패킷 구조입니다.
